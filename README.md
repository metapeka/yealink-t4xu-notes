# Yealink T4xU — разбор прошивки

Рабочие заметки по реверс-инжинирингу прошивки IP-телефонов Yealink серии T4xU (T41U/T42U/T43U/T44U/T44W/T46U/T48U на SoC Rockchip RK3308) и по пути к собственным функциям прошивки.

**Аппарат:** SIP-T43U, прошивка `108.86.14.4`.

## Что здесь есть

- **`index.html`** — страница с состоянием работ, схемой пакета и пошаговой инструкцией для человека с аппаратом.
- **`docs/`** — подробные документы:
  - `FINDINGS.md` — что установлено (с пометками «факт / гипотеза»);
  - `BRANCHES.md` — ветки работ и памятка по аппарату;
  - `PLAN.md` — порядок работ и гейты;
  - `TOOLS.md` — инструменты и проверки;
  - `BRANCH_D.md` — проект подмены `rfs`;
  - `INSTRUCTION_DUMP.md` — инструкция для человека с аппаратом.

## Коротко о результатах

- Формат ROM-пакета разобран полностью: заголовок 128 Б, блоки `version` / `rfs` / `bootloader`, слои `cypher3` и LZMA. Пересборка совпадает с оригиналами побайтово.
- Апдейтер `108.86.14.4` идентичен апдейтеру `108.86.0.118`: подписи и ключей нет, проверяются только magic, CRC и размеры.
- Rootfs закрыт слоем `ubifs crypto` (324 из 342 LEB). Ядро лежит в том же томе.

## Ограничения

Данные по конкретному устройству (MAC, серийные номера) в публикации скрыты. Сами файлы прошивок не публикуются: это чужой проприетарный код, права на него не наши.

Материал публикуется «как есть», для исследования совместимости и восстановления собственного оборудования.
