# Чего нельзя делать

Страница-предупреждение. Всё остальное можно читать как отчёт, а это — как технику безопасности: коротко, без оговорок.

<div class="stop">
<b>Три правила, которые закрывают почти все способы испортить аппарат</b>
<ul>
<li><b>Питание не подаём.</b> Трубка работает от своего адаптера; переходник даёт только землю и сигнал.</li>
<li><b>Сначала только приём.</b> К неизвестному контакту подключаем вход приёмника, а не выход передатчика.</li>
<li><b>Уровень проверяем у переходника, а не по надписи.</b> «Модуль на 3,3 В» — про питание модуля; у многих CH340 на TX по умолчанию 5 В.</li>
</ul>
</div>

## Чем работаем и чего с этим нельзя

| Инструмент | Нельзя | Чем кончится |
|---|---|---|
| Питание 3,3 В / 5 В | подавать на тест-площадки | сгоревший MCU — тот самый, что выдаёт ключ |
| Мультиметр, щупы | касаться двух выводов сразу | замыкание, мёртвая плата |
| USB-UART переходник | подключать до найденной земли | сигнал уходит в питание |
| USB-UART переходник | подавать 5 В с TX в линию телефона | выгоревшая приёмная линия |
| Паяльник | выпаивать NAND без опыта | оторванные площадки, плата в мусор |
| Консоль U-Boot | `nand erase`, `nand write`, `saveenv`, `mw`, `cp.b` | стёртый загрузчик, телефон не включается |
| Пакет прошивки | заливать, пока копия флеша не снята и не сверена | откатываться некуда |

## Категорически

1. **Не подавать питание на тест-площадки.** Ни 3,3 В, ни 5 В. Никогда.
2. **Не подключать TX переходника, не измерив его уровень.** Проверка: мультиметр между TX модуля и GND без нагрузки, должно быть около 3,3 В.
3. **Не вводить в консоль загрузчика команды записи.** Набор работает только на чтение; всё, что меняет флеш, — отдельное решение и отдельный разговор.
4. **Не прошивать пакет, пока не снята и не сверена копия флеша.**
5. **Не выпаивать микросхему памяти** без программатора и опыта: сорванные площадки не восстанавливаются.
6. **Не оставлять трубку в консоли загрузчика.** В конце — `reset`, иначе при следующем включении она покажется мёртвой.
