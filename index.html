Что сделано

Формат пакета

Заголовок 128 Б, big-endian. Блоки: version (ELF), rfs (LZMA), bootloader (cypher3). Поля cipher: 0 — как есть, 1 — LZMA, 3 — cypher3, 0x83 — AES-256.

Проверено: пересборка 86.0.118, 87.0.20 и 86.14.4 совпадает с оригиналом побайтово.

Апдейтер

version.elf из 108.86.14.4 байт в байт равен апдейтеру 108.86.0.118: статическая сборка, крипто-импортов нет, проверяются только magic, CRC заголовка и блоков, размер распаковки.

Следствие: подпись содержимого не проверяется, ключи для 86.x не нужны.

Слой ФС

Rootfs — UBI (PEB 128 КиБ, LEB 124 КиБ). Из 342 LEB 324 обёрнуты vendor-узлом 38 26 90 05, 9 — обычные UBIFS-узлы, 6 — стёртые.

Ядро /uImage лежит в том же томе, то есть тоже внутри зашифрованной части.

Эмулятор апдейтера

Собран запускаемый в Unicorn скелет: PIE грузится по адресам, импорты libc/OpenSSL подменяются хуками, вызывается любая функция.

Показал для V87: публичный ключ выводится из памяти устройства (/dev/mem), а не из пакета.

Как устроен пакет

ver 108.86.14.4  crypto 0x3  len 0x23E29B0  tail 0
  version     off 0x80      len 0x9CB50    cipher 0   ← ELF-программа
  rfs         off 0x9CC50   len 0x22E5CDC  cipher 1   ← LZMA → UBI
  bootloader  off 0x23829B0 len 0x60000    cipher 3   ← cypher3 → LOADER + U-Boot

Апдейтер пишет блоки прямо в /dev/mtdN; слой шифрования ФС создаётся не им, а приходит готовым в пакете.

Инструкция человеку с аппаратом

Порядок важен: сначала то, что ничего не ломает.

  1. Не дать обновиться. Не подключать к сети провайдера, отключить Auto Provision и RPS. Сейчас на трубке 108.86.14.4 — это рабочая база.
  2. Снять версию. OK → Status: Firmware Version и Hardware Version. Либо веб: http://IP → admin → Status.
  3. UART-лог. Найти пятаки UART у SoC, подключить USB-UART на 3.3 В, 115200 8N1, GND общий. Включить трубку и записать лог с нуля.
  4. Если в логе есть Hit any key to stop autoboot — остановить загрузку и снять вывод mtdparts и nand info, затем дамп. nand read берёт только main area, OOB снимается отдельно.
  5. Если консоли нет — снять наклейку с микросхемы и сфотографировать маркировку. Ничего не выпаивать до подтверждения модели.
  6. Снять дважды и сравнить SHA-256 — так отсекается ошибка чтения.

Чего не делать

  • Не прошивать, не стирать, не обновлять, не запускать «восстановление».
  • Не выпаивать чип, пока не подтверждена модель по фото маркировки.
  • UART — только 3.3 В: 5-вольтовый TX может выжечь вывод SoC.
  • При чтении программатором плата обесточена; питать от платы и программатора одновременно нельзя.
